Large-Page Version Compare for Confluence — Documentation

Documentation

What this app does

Large-Page Version Compare adds one item, Compare large versions, to the ••• menu of a Confluence page. Pick two versions of the page and it lists every block that was added, removed or modified between them, on pages of any size up to 25 MB per version.

It exists because Confluence's own compare stops being reliable on large pages. Measured on a Confluence Cloud site on 2026-09-29: on a 217 KB page native compare reported 114 edits where 142 blocks had been edited; on a 543 KB page it collapsed to a whole-page delete and re-insert; on a 4.88 MB page the browser tab froze and crashed. It is read-only and changes nothing.

Getting help

Email support@maxpetrov.pp.ua. One person reads that mailbox — the one who wrote the app — and every request gets a first reply within two business days, Monday to Friday. That is the window a part-time maintainer can hold every week rather than on a good one; most replies land sooner.

Say which two versions you compared and what the summary line showed — the change count and both block counts — and, for a change that looks wrong, its number from the Change k of C counter. If a read failed, the message names the version and the HTTP status Confluence gave, and that line is the fastest thing to send.

Where to find it after installing

There is exactly one place this app appears, and nothing else in Confluence changes.

  • Open any Confluence page or live doc, then its ••• (More actions) menu, then Compare large versions. A window opens over the page.

  • No page under Apps, no macro, no space tool, no page byline item and no administration entry. There is no setup form.

  • The window opens with the previous version as From and the current version as To, and one Compare button. On a page with only one version it says so and shows no Compare button.

Comparing two versions

The version pickers list the newest 250 versions by number, date and version message; Load older versions fetches the rest. Press Compare and the app reads both versions as you, through your own Confluence permissions, and compares them in the window.

A version you cannot read, or a read Confluence refuses, is shown with the version number and the HTTP status Confluence gave; Try again re-reads only that version. A version above 25 MB of page data is named with its size and nothing is compared.

Reading the result

The summary strip gives the changes by kind — added, removed, modified — and the block count of each version. Next and Previous step through the changes with a Change k of C counter, Go to change jumps to a number, and the heading outline of the To version selects the first change at or after the heading you pick.

The selected change is rendered as Confluence content. Inside a modified block, removed words are struck and inserted words underlined. A changed table, list, panel, expand or layout is compared one level down, so the detail names the row or item — row 17 of 240 — and renders only what changed. Two versions that differ only in formatting noise show 0 changes with both block counts.

What it does with your data

The app runs entirely on Atlassian infrastructure and has no backend: both versions are read into the open window and compared there, and closing the window discards them. It stores nothing, declares no remote hostname and opens no network connection of its own, so nothing it reads leaves Atlassian.

The full privacy policy and the security policy are separate pages; their URLs are on this app's Marketplace listing.

Known limitations

These are the limits the app was built against, written down here rather than discovered after purchase.

  • Third-party and Forge macros are compared by their stored parameters and body, not rendered; the detail shows "Macro: <extensionKey>" in their place

  • Images and attachments: a changed image reference (media id, width, alt) is a change; the file's pixels are never compared

  • A moved block is reported as one removal and one addition, not as a move

  • Word-level highlight stops at 50,000 words in one changed block (for a table or list, counted over its changed rows or items only); a longer one shows before and after whole, with its word count

  • Pages and live docs only. Blog posts, whiteboards and databases are not compared; the ••• item on a blog post opens the unsupported state

  • Two versions of one page. No cross-page compare (Compare Any Two Pages ships it)

  • Published versions only; unpublished drafts are not listed

  • Formatting-only noise that Confluence itself adds (internal ids, auto-size flags, empty attribute sets, a macro's server-added parent id) is ignored by design; inline-comment markers are ignored too

  • Up to 25 MB of page data per version (2.5× the largest measured, 10.07 MB); above it the app says so and compares nothing

  • No export, email, comment or saved report; read-only, and the result lives in the open modal only

  • The version picker shows number, date and version message, not the author's name

  • Cloud only
